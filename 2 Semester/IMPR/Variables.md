```c
// local variables
int x = 5;         // integer
double y = 3.14;   // floating point
char c = 'A';      // single character
```
- Store values
- Must be declared before use
- Local variables live on stack


```C
// printing variables
printf("%d", x);    // int
printf("%lf", y);   // double
printf("%c", c);    // char

// scanning variables
scanf("%d", &x);
scanf("%lf", &y);
scanf("%c", &c);
```
